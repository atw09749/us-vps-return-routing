## FAQ

**美国 VPS 延迟多少算正常？**
美国西海岸到国内，150ms 到 220ms 是常见区间。低于 150ms 说明线路做了明显优化，高于 250ms 通常意味着回程绕路。不同测评的测试点、运营商、时间段都不同，146ms、164ms、206ms 这些数字不能放在一起比大小，只能各自参考。

**CN2 GIA、AS9929、AS4837 有什么区别？**
三者都是大陆方向的高级线路，区别在归属和适用人群。CN2 GIA 是中国电信的精品承载网，三网回程都走它时延迟最稳，价格也最高；AS9929（联通 CUII）对联通用户最友好；AS4837 是联通骨干网，带宽成本相对低，所以常被用来做大带宽和不限流量产品。选哪条，先看自己家宽带是哪家运营商。

**原生 IP 和住宅 IP 是一回事吗？**
不是。原生 IP 指的是 IP 注册地和机房归属一致，没被转卖或广播到别处；住宅 IP 指的是 IP 挂在家庭宽带线路上。机房双 ISP 原生 IP 和家宽住宅 IP 在平台风控里的权重不同，后者更"像真人"。丽萨主机官网写的是"双 ISP 家宽住宅美国原生 IP"，如果你的业务对 IP 类型极敏感，先买单台实测再决定是否批量上。

**流量用超了会怎样？**
按流量计费的档位，官网产品页没有逐条写明超额后的处理方式。有明确不限流量档位的商家通常会限速不断网，但这属于推断，不能当结论。下单前提交工单问清楚，比事后处理省事。
